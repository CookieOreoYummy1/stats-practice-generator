# Live smoke-test review

Model: `openai/gpt-oss-120b`. Raw generated questions, solutions, timings, and grading responses are saved in `live-smoke.json`. This run exercised FastAPI routes in-process with real Groq calls, without changing the running demo's cache.

## Results

- Offline suite: 81 passed, 2 dependency deprecation warnings.
- Live generation: 6/9 HTTP 200; sampling/CLT, hypothesis testing, and regression returned clean rate-limit 502s.
- Public responses excluded solution fields in all six successful generations.
- Live grading: equivalent fraction `1/4` for `0.25` passed. Correct mean `5`, incorrect mean `100`, and equivalent percentage `25%` returned 502s and are inconclusive, not incorrect grading verdicts. The grading wrapper hides the underlying provider error, so its exact cause is not recorded; rate limiting was observed during generation in the same run.

## Formatting findings from actual response text

- Continuous-distribution solution splits `$$`, formula text, and closing `$$` across separate list entries. The current frontend renders each entry independently, so those equations cannot form a single Markdown math block.
- Probability, discrete-distribution, and ANOVA final answers contain LaTeX commands outside dollar delimiters.
- An ANOVA solution step opens a parenthesis math delimiter and closes with `$$`, leaving mismatched delimiters.
- The confidence-interval response contains doubled command backslashes; existing normalization handles the observed known commands, but does not correct the numerical mistake.

Actual browser rendering was not inspected. No application functionality was modified during this test run. These findings mean passing unit tests alone does not establish demo readiness.

## Repeat the opt-in live test

From the repository root, with dependencies and `.env` configured:

```powershell
.\venv\Scripts\python.exe -m scripts.live_smoke
```

This uses real Groq quota: nine generation requests and four grading requests, plus the application's bounded retries and a startup credential check. It overwrites `live-smoke.json`. Wait for quota recovery before another run. A nonzero exit status indicates failed requests or unexpected grading verdicts; inspect the report to distinguish the two.
